# 2026-10-26 · 首屏性能优化

## 诊断（先造尺子）
- 新增 `scripts/perf-check.mjs`：Playwright + CDP，Slow 4G（400ms RTT / 400kbit）+ CPU 4× + 390×844，测 FCP / 首卡 / 首图 / LCP / 字节 / 请求数，`--delay-fonts` 模拟 Google 不可达，`--warm` 测复访。
- 改前：FCP 5.42s，首卡 7.91s，首图 10.98s，340kB / 23 请求；字体延迟 6s 后 → 7.56 / 10.07 / 13.31s（复现用户说的 10-15s）。

## 四层原因 + 对应改法
1. `index.html` 里 Google Fonts 的 CSS 是**渲染阻塞**（跨域样式表不返回就不画）→ 删除，字体退回系统栈（tailwind `fontFamily.sans`）。改后字体再拖 6s，FCP 不变。
2. bundle 在 4× CPU 下要 4.1s 才执行完，React 骨架在此之前不存在 → `index.html` 内联**静态骨架**（~1.5kB，纯 CSS，6 张卡 + 品牌环 + "Curating…"），React 挂载后被 `ProductGrid` 的 10 卡骨架接棒。**改网格布局要同时改两处**（注释已写）。
3. 亚马逊图 `_AC_SY741_`（17.6kB）塞进 169px 卡片 → `src/utils/image.js` 改写 token + `srcSet 320/640 + sizes`；实测 320 = 5.8kB。`imageSrcSet` 无 token 时返回 undefined（不撒谎）；`ProductImage` 换 src 时必须**清掉 srcSet**（srcset 优先级高于 src）。
4. 每次访问都全量拉目录 → `productStore` 模块导入时同步读 `sessionStorage`（`mako_catalogue_v1`，12h TTL）先行渲染，网络回来原地替换；`status` 只在无数据时才回 `loading`（否则 hydrated 网格闪回骨架）。

## 顺手
- 后台路由 `React.lazy`：入口 282kB/79gzip → 139kB/38gzip，ProductsPage 变 130kB 按需分包；`AdminGate` 保持 eager。
- 匿名不再请求 `asins`（RLS 只给 admin，必然空数组），有会话才拉。
- Realtime 延后到 `requestIdleCallback`（兜底 2.5s）。
- Header/CategoryNav/BottomBar/ProductCard 全部 memo（ProductCard 需自定义比较，父组件每次重建 `lines`）；搜索 `useDeferredValue`。
- 骨架屏计时从「写死 450ms」改为「数据没到就画，到了再留 250ms」；`catalogueStatus==='error'` 有重试按钮（之前会永远卡骨架）。
- preconnect Supabase 试过无效（仅 40ms），已删并在注释记录。

## 详情弹层图文分离（ProductDetail）
- 用户先要方案后改码；两点确认：①手机吸住时收缩到 30vh ②桌面底栏只占右栏。
- **一套 DOM 两套布局**：滚动容器在 `split` 下 `display: contents`，图片/信息直接成网格子项；图片 `row-span-2` 占左列，信息右列自滚，底栏 `col-start-2 row-start-2`。没有复制图片节点（否则两次 640w 请求 + 两份 a11y 节点）。
- `tailwind.config.js` 新增 raw screen `split: '(min-width: 1024px), (min-width: 768px) and (orientation: landscape)'`——横屏手机也走双栏；同一条查询在 `ProductDetail.jsx` 的 `TWO_PANE_QUERY` 常量里重复一次，两处必须同步。
- 手机吸顶：`sticky top-0`，56px 吸住 / 24px 还原（迟滞），高度 `clamp(180,36vh,380)` → `clamp(160,30vh,260)`；**门槛 100px**（= 56 + 收缩量约 40）：内容超出不足 100 就不收，否则收掉的 40px 会吃掉滚动行程、scrollTop 被钳位往回跳。门槛只在「未吸住→吸住」时判一次，避免 scrollHeight 反馈打架。吸住后加 1px 分隔 + 轻阴影。
- `CrossfadeImage`：新图游离 `Image()` 预载（旧图继续显示）→ 新图垫底、旧图盖顶淡出 300ms → 卸载；`motion-reduce:hidden`。让旧图淡出而不是新图淡入（后者需要二次渲染，掉帧就闪）。
- Modal 传 `maxWidth="max-w-lg split:max-w-5xl"`；信息栏 `split:pr-12` 给关闭按钮留位。
- 测试：`smoke:gate [5ac]` 11 条（1280×800 双栏/底栏归属/自滚/换图/淡出层清理；375×568 吸顶+收缩+换图；844×390 横屏分栏+无横向溢出）；`npm test` **1534**；`smoke:gate` **386/0**；build 入口 164.79 kB / 45.87 gzip。
- 踩坑：`[5ab]` 点了分类没还原，`[5ac]` 的 `goto('#/')` 是 hash 导航不重挂载，React 状态（分类筛选）残留导致按货号搜不到商品 → 在 [5ab] 结尾点回 All，并在 [5ac] 的 openSheet 里 `reload()`。
